## 核心概念

### 1. LSTM 记忆的局限性

标准 LSTM 的记忆存储在隐藏状态 $h_t$ 和细胞状态 $c_t$ 中，
它们都是**单一的向量**。这意味着：

- 所有信息被压缩到一个固定大小的向量中
- 不同的记忆片段无法互相交互
- 随着序列增长，早期信息被逐渐覆盖
- 缺乏显式的关系推理能力

一个关键问题是：**记忆的不同部分之间是否应该互相"对话"？**

### 2. 核心创新：记忆槽 + 自注意力

Relational RNN 的核心思想是将记忆从**单一向量**扩展为**多个记忆槽** (memory slots)，
并使用**多头自注意力**让记忆槽之间互相交互。

具体来说：

- 记忆不再是单个向量 $h_t \in \mathbb{R}^d$
- 而是一个记忆矩阵 $M_t \in \mathbb{R}^{N \times d}$，包含 $N$ 个记忆槽
- 每一步，新的输入与所有记忆槽通过自注意力交互
- 记忆槽之间也通过自注意力互相交互

这样，记忆的不同部分可以**关联、比较、更新**——这就是"关系"的含义。

### 3. Relational Memory Core (RMC) 结构

RMC 的每一步更新过程如下：

**步骤 1：输入整合**

将当前输入 $x_t$ 与每个记忆槽拼接或广播：

$$\tilde{M}_t = [M_{t-1}; x_t] \quad \text{(将输入作为额外行拼接到记忆矩阵)}$$

**步骤 2：多头自注意力**

在扩展后的矩阵上应用多头自注意力 (Multi-Head Attention, MHA)：

$$A_t = \text{MHA}(\tilde{M}_t, \tilde{M}_t, \tilde{M}_t)$$

这里的 Query、Key、Value 都来自同一个矩阵（自注意力），
让每个记忆槽可以关注输入和所有其他记忆槽。

**步骤 3：门控更新**

使用类似 LSTM 的门控机制来更新记忆：

$$M_t = \sigma(W_g [A_t; M_{t-1}]) \odot \tanh(A_t) + (1 - \sigma(W_g [A_t; M_{t-1}])) \odot M_{t-1}$$

门控机制确保：
- 模型可以选择性地保留旧记忆或写入新信息
- 避免记忆被注意力操作完全覆盖
- 保持训练稳定性

### 4. 多头注意力的作用

在 RMC 中，多头注意力不仅用于"选择相关信息"，
更重要的是实现**记忆槽之间的关系推理**：

- **每个头关注不同类型的关系**：一个头可能关注时间顺序关系，
  另一个关注语义相似性
- **并行处理多种关系**：$H$ 个头可以同时提取 $H$ 种关系
- **信息交换**：通过注意力，一个记忆槽的信息可以传播到其他槽

## 关键公式

### 多头自注意力

$$\text{MHA}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_H) W^O$$

$$\text{head}_h = \text{Attention}(Q W^Q_h, K W^K_h, V W^V_h)$$

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

### 记忆更新（简化形式）

$$A_t = \text{MHA}([M_{t-1}; x_t])$$

$$g_t = \sigma(W_g \cdot [A_t, M_{t-1}])$$

$$M_t = g_t \odot \tanh(A_t) + (1 - g_t) \odot M_{t-1}$$

### 输出计算

$$h_t = \text{Flatten}(M_t) \quad \text{或} \quad h_t = \text{Mean}(M_t)$$

输出可以是记忆矩阵的展平、均值池化、或特定槽的值。

## 直觉理解

### 从 LSTM 到 Relational RNN 的演进

可以用一个比喻来理解这个演进：

**LSTM** 像是一个人用**一本笔记本**记东西。
所有信息写在同一页上，互相覆盖。
容量有限，早期笔记被后来的覆盖。

**Relational RNN** 像是一组人围坐开会，
每个人手里有**自己的笔记** (记忆槽)，
每一步他们会**互相讨论** (自注意力)，
然后各自更新自己的笔记 (门控更新)。

这种设计的好处是：
- 记忆容量成倍增加（$N$ 个槽 vs 1 个向量）
- 不同槽可以专门存储不同类型的信息
- 通过注意力，槽之间可以协调和推理

### 为什么门控很重要

没有门控机制，每一步的注意力操作都会完全重写记忆。
这会导致：

- 长期记忆被频繁擦除
- 训练不稳定，梯度流不畅
- 模型难以学习何时保留旧信息

门控机制（借鉴自 LSTM）让模型学会：
"这个信息很重要，保留它"
vs "这个信息过时了，用新的替换"

### 自注意力 vs 外部记忆访问

RMC 的记忆交互是**内部的**（记忆槽之间的自注意力），
而 NTM (Day 18) 的记忆访问是**外部的**（控制器访问独立的记忆矩阵）。

| 维度 | Relational RNN | NTM |
|---|---|---|
| 记忆位置 | 隐藏状态的一部分 | 独立的外部矩阵 |
| 交互方式 | 记忆槽之间自注意力 | 控制器通过读写头访问 |
| 记忆容量 | 固定（$N$ 个槽） | 可扩展 |
| 计算方式 | 自注意力 | 内容/位置寻址 |

## 历史背景

### 从关系网络到关系 RNN

Relational RNN 是 DeepMind 团队在关系网络 (2017) 之后的自然延伸：

- **关系网络** (Day 16) 证明了显式关系推理对静态场景推理的价值
- **Relational RNN** 将这一思想推广到**序列处理**中
- 核心贡献：让 RNN 的记忆具备了关系推理能力

### 记忆增强神经网络的谱系

Relational RNN 位于以下发展脉络中：

```
LSTM (1997)
  ↓ 更大的外部记忆
Neural Turing Machine (2014)
  ↓ 更好的记忆交互
Relational Memory Core (2018)
  ↓ 完全基于注意力的序列建模
Transformer (2017, 并行发展)
```

有趣的是，Transformer 从另一个方向达到了类似的设计：
完全基于注意力的信息交互。
RMC 可以看作是 "将 Transformer 的注意力嵌入 RNN 框架"的尝试。

### 与 Transformer 的关系

Relational RNN 和 Transformer 在发表时间上几乎重叠：

- Transformer (2017) 完全抛弃了循环结构
- RMC (2018) 试图在循环结构中引入注意力

历史证明，Transformer 的完全注意力方案更为成功。
但 RMC 的思想——记忆槽之间的关系推理——
在后续的许多工作中得到了体现（如 Memory Transformer、Memorizing Transformer 等）。
